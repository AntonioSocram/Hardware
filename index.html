Conheça os principais Hardwares

O hardware é a parte física do computador. Conheça seus principais componentes e suas funções.

Ver componentes

Principais componentes

As peças mais importantes de um computador.

Processador (CPU)

É responsável por executar instruções e realizar cálculos necessários para o funcionamento do computador.

Peça essencial

Placa de vídeo (GPU)

Processa imagens, vídeos e gráficos. É muito importante para jogos, edição de vídeo e programas 3D.

Importante para jogos

Memória RAM

Armazena temporariamente os dados dos programas que estão sendo utilizados pelo computador.

Memória temporária

SSD / HD

São dispositivos utilizados para armazenar o sistema, programas, jogos e arquivos.

Armazenamento

Fonte de alimentação

Fornece a energia necessária para os diferentes componentes do computador.

Energia do PC

Placa-mãe

É a principal placa do computador. Ela conecta processador, memória, armazenamento e outros componentes.

Conecta tudo

Cooler

Ajuda a controlar a temperatura do processador e evita o superaquecimento.

Controle de temperatura

Periféricos

São dispositivos conectados ao computador, como teclado, mouse, monitor, headset e webcam.

Dispositivos externos

Curiosidades

Algumas informações interessantes sobre hardware.

SSD é mais rápido

Um SSD normalmente possui velocidades de leitura e escrita superiores às de um HD tradicional.

RAM não é armazenamento

A memória RAM trabalha temporariamente com os dados. Quando o computador é desligado, esses dados são perdidos.

GPU e jogos

A placa de vídeo realiza grande parte do processamento gráfico utilizado nos jogos.

Compatibilidade

É necessário verificar se as peças são compatíveis, considerando conexões, soquete, memória e fonte.
